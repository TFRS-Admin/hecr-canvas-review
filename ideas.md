# HECR Canvas Review — Design Direction

## Three Possible Approaches

### 1. Operations Blueprint Ledger
**Very Brief Intro:** A dark-navy field manual meets an architectural drawing board: disciplined, legible, and built for decision-making rather than marketing. The page makes a complicated system feel inspectable, not mysterious.
**Probability:** 0.07

### 2. Client Journey Atelier
**Very Brief Intro:** A warm editorial workshop uses large paper cards, practical annotations, and relaxed hierarchy to show the human journey behind the automation. It would make the architecture feel approachable and human-first.
**Probability:** 0.04

### 3. Signal Room
**Very Brief Intro:** A high-density dark operations console uses live-looking routes, bright signal markers, and compact controls to visualize a business system in motion. It would foreground the feeling of monitoring and orchestration.
**Probability:** 0.09

## Chosen Approach: Operations Blueprint Ledger

### Design Movement
**Modern technical editorial** with the calm precision of a field manual, a systems-architecture board, and a consulting dossier. It is not a SaaS dashboard and it is not a sales landing page.

### Core Principles
1. **Source-faithful first:** The interface exposes the current canvases and their labels; it does not silently rewrite or sanitize the system.
2. **Inspectability over spectacle:** Every section is easy to scan, compare, and discuss in a working session.
3. **One system, many lenses:** The same HECR operation is shown through five distinct but interconnected views.
4. **Signals carry meaning:** Color is reserved for functional distinctions such as customer path, human handoff, tool type, and pending/held status.

### Color Philosophy
Deep **midnight navy** represents governance, auditability, and the operating core. Warm ivory and blueprint paper create a calm working surface. Cobalt denotes system movement, emerald denotes safe or established paths, orange flags commercial/human decision points, and violet identifies AI-assisted interpretation. The result should feel grounded rather than “techy.”

### Layout Paradigm
A fixed left **canvas index rail** sets up the page as a physical review binder. The hero gives a single system thesis, while the rest of the page uses wide, horizontally flowing route boards that remain readable as individual project lenses. Avoid a centrally stacked card-grid dashboard.

### Signature Elements
1. A technical **rail index** with numbered canvas markers and status dots.
2. A repeated **route band**: small labeled nodes connected by sharp, deliberate directional lines.
3. **Margin notes** that preserve key labels such as “held,” “not finalized,” or “pending confirmation.”

### Interaction Philosophy
The page behaves like a review board. Selecting a canvas in the rail scrolls to it and updates the active marker. Hovering a route node lifts it slightly and reveals that it is an inspectable component, not decoration.

### Animation
At load, the header, rail, and hero route settle in with restrained opacity/translation transitions. Route lines use a very subtle travelling highlight only when reduced motion is not requested. Canvas sections do not bounce or animate continuously; this is a decision surface, not a control room simulation.

### Typography System
**Barlow Condensed** supplies the tall, practical display voice for titles, stage numbers, and system labels. **DM Sans** handles supporting prose and dense working text. Barlow Condensed is uppercase for navigation and operational labels; DM Sans remains sentence case for explanations.

### Brand Essence
**A visual decision room for turning HECR’s current system maps into one governed, inspectable operating picture.**

**Personality adjectives:** Structured, candid, practical.

### Brand Voice
Headlines are direct, grounded, and specific; microcopy makes uncertainty visible rather than smoothing it over.

Example lines:

> “Five canvases. One system to inspect.”

> “Preserve the map first. Change it only by decision.”

### Wordmark & Logo
The wordmark pairs a compact linked-node mark with compressed uppercase lettering. The mark is a five-node path representing inputs, people, tools, decisions, and proof.

### Signature Brand Color
**Ledger Cobalt — #2B63D9**. This is the single recognizable signal color for system movement and active review state.

## Style Decisions

- Keep current/legacy/held language visibly intact. The page is a review artifact, not a polished claim of completeness.
- Use text-based routes and diagram boards; do not hide operational detail behind decorative imagery.
- Keep the visual emphasis on the operating maps, with generated imagery used only for texture, hierarchy, and brand cohesion.
- The left canvas index rail is a mandatory sticky binder motif with numbered markers, status dots, and Ledger Cobalt reserved for the active review state.
- Route bands are the dominant visual primitive on every canvas. Matrix content must still show grouping, status, or dependency rather than becoming generic card-grid content.
- The compact five-node mark and compressed uppercase HECR Canvas Review wordmark appear both in the binder rail and the page hero as owned identity anchors.
